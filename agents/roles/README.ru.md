# Машинные роли агентов Colibri / Fone

Этот каталог описывает не профессии людей, а роли, которые агент может получить на время lease.

Файлы:

- `schema.json` — JSON Schema роли.
- `catalog.json` — полный каталог.
- `catalog.jsonl` — построчный формат для загрузки в рантайм/индекс.

Правило: агент не получает постоянную власть. Он получает временный capability profile на конкретную задачу.
