# Vista Product API

The authoritative OpenAPI document is generated by FastAPI at `/openapi.json`; interactive documentation is available at `/docs` in controlled environments.

Core groups:

- `/api/os/*` — signed sessions, intent resolution and workspace state;
- `/api/estimates/*` — estimate CRUD, line items, versions and calculation;
- `/api/artifacts/*` — authenticated documents;
- `/api/public/share/*` — expiring client projection and client document download;
- `/api/factory/*` — tasks, leases, artifacts, events and verifier state;
- `/api/nodes/*` — registration, heartbeat, drain/resume;
- `/api/developer/*` — Vista project API keys and compatibility metadata.

Every protected request uses `Authorization: Bearer <vista_session_... | vista_sk_...>`.
