## Главный открытый проект

### [rd8r8bkd9m-tech/kolibri-ai-platform](https://github.com/rd8r8bkd9m-tech/kolibri-ai-platform)

Kolibri AI Platform — рабочий репозиторий, где я собираю AI-продукт как единую
систему:

- **React SPA/PWA** для пользовательского интерфейса и мобильного сценария;
- **FastAPI backend** для чата, документов, смет, billing-интеграций и API;
- **Agent Factory** для удаленного исполнения задач и координации агентов;
- **Deterministic estimates** для строительных расчетов с audit trail;
- **FormulaLM R&D** для проверки формульного подхода к LLM-задачам;
- **GitHub workflow** для PR, CI, документации и прозрачного инженерного следа.

## Инженерные принципы

- Детерминизм важнее магии.
- Агент должен возвращать проверяемый результат, а не красивый статус.
- LLM может помогать с пониманием задачи, но расчеты и контракты должны быть проверяемыми.
- FormulaLM остается R&D-направлением: сначала метрики, потом громкие выводы.
- Секреты, токены, приватные пути и локальные env-файлы не живут в публичных README.
- Хороший AI-продукт соединяет UX, backend, инфраструктуру, тесты и документацию.
