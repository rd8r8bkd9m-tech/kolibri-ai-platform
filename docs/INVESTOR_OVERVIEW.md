# Investor Overview

KolibriAI Platform is a controlled AI factory platform for task routing, agent work, artifacts, Telegram/Fabric operations, public site delivery, and release evidence.

Calibri V1 turns the active runtime into a clearer platform:

- API-first Control Plane;
- worker agents through contracts, not SSH;
- traceable task/event/artifact flow;
- protected secrets and bootstrap;
- public presentation separated from private operations.
