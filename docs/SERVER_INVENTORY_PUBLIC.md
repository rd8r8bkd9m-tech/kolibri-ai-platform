# Server Inventory Public

This file intentionally excludes IP addresses, private hostnames, credentials, tokens, deploy paths, and private inventory.

Public roles:

- backend/API node group;
- frontend/site delivery;
- factory control sidecar;
- Telegram/Superfactory gateway;
- worker/agent host group;
- release/artifact evidence storage.

Private inventory belongs in ignored files such as `ops/SERVER_INVENTORY.private.md`.
