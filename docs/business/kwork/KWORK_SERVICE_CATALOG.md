# Kwork Service Catalog

## Catalog Strategy

Start with small fixed-scope offers that can be delivered honestly and quickly. The current single SPA/PWA kwork is expensive and high-competition. Add narrow services that create first trust signals, reviews and repeatable delivery.

## 1. Создам Telegram-бота с AI-ассистентом для вашего бизнеса

- Category suggestion: Разработка и IT > Скрипты, боты и mini apps > ИИ-боты / Чат-боты.
- Short description: Разработаю Telegram-бота, который отвечает клиентам, собирает заявки, помогает с документами или автоматизирует повторяющиеся задачи.
- Included: simple bot logic, commands/buttons, basic AI сценарии, launch instruction, test scenario, 1-2 revisions inside agreed scope.
- Not included: complex CRM integrations, paid API keys, hosting/domain, 24/7 support, bypassing service rules.
- Delivery time: 3-5 days.
- Base package: bot сценарий + command/buttons prototype.
- Standard package: bot + simple AI/API integration + deployment instruction.
- Premium package: bot + AI flow + webhook/API integration + extended testing.
- Extras: additional commands, Google Sheets integration, mini admin panel, deployment support.
- Buyer requirements: bot goal, examples of questions/answers, desired actions, Telegram bot token availability, integrations, deadline.
- FAQ: Can ChatGPT/local LLM be connected? Yes, after agreeing API/infrastructure. Can you help launch? Yes, with instructions and smoke test. Can it be expanded later? Yes, as a separate order.
- Portfolio idea: anonymized Telegram bot flow diagram and screenshots without secrets.
- Risk notes: no guarantee of sales/conversion; external API costs are not included.
- Revision policy: 1-2 small revisions within agreed scope.
