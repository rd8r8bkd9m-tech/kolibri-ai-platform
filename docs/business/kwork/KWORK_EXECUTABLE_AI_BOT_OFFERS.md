# Kwork Executable AI Bot Offers

This file defines only the offers that can be executed by Vladislav/Codex/Kolibri now. Use these as the safe commercial menu. Do not sell vague "anything with AI" work.

## Execution Principles

- Every order must have a fixed first result.
- Every bot order starts with scenario and requirements.
- External API keys, paid provider accounts, domains, hosting and CRM access are not included unless explicitly agreed.
- Secrets are not accepted in public chat; use a safe handoff method.
- AI answers require human review for legal, medical, financial, security and other high-stakes decisions.
- No spam, fake accounts, bypass automation, credential harvesting, platform manipulation or grey monetization.


- buttons/commands;

- manager handoff;

- launch instruction.

Good clients:

- education/expert;
- local services;
- online consultations;

Not suitable:

- complex marketplace or SaaS in one small order.
