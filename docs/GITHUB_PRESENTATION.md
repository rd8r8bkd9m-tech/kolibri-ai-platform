# GitHub Presentation

Use these as the public front door:

- `README.md`
- `docs/INVESTOR_OVERVIEW.md`
- `docs/ARCHITECTURE_PUBLIC.md`
- `docs/ROADMAP.md`
- `docs/SECURITY_PUBLIC.md`
- `docs/SOURCE_OF_TRUTH.md`
- `release/final-report.md`

Keep private operations out of GitHub-facing docs:

- raw secrets;
- private hostnames/IPs;
- deploy paths;
- `ops/telegram.env`;
- local logs and generated output.
