# Модель безопасности

## Базовая политика

- По умолчанию **запрещены** опасные действия.
- Любое действие с высоким риском обязано пройти `PolicyDecision`.
- Нет прямого запуска shell с UI или от модели.
- Команды выполняются только через абстракцию sandbox.
- Все операции с секретами — через `SecretRef`, без хранения сырого значения в событиях/логе.

## Ключевые правила

1. `shell` только через policy-approved профили.
2. `production deploy` и `publish` только после явного approval.
3. Root execution запрещён по умолчанию.
4. Terminal доступ в UI должен быть approval-only / mocked в MVP.
5. Каждое решение policy должно быть auditable.

## Ограничения v1

- Полный sandbox (gVisor/Firecracker) ещё roadmap.
- Vault/mTLS для прод-сегмента — roadmap.
- PTY-интеграция с удалёнными shell — отключена до реализации approval-потока.
