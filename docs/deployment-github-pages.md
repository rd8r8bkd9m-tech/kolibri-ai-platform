# GitHub Pages Deployment

GitHub Pages exists in `.github/workflows/pages.yml` and this branch has history for `kolibriai.ru` Pages deployment.

Safe actions:

- build frontend locally;
- inspect Pages workflow;
- update docs;
- prepare DNS instructions.

Approval required:

- DNS changes;
- REG.RU changes;
- public exposure changes;
- production API target changes.

Current public DNS instructions are in `release/dns-instructions.md`.
