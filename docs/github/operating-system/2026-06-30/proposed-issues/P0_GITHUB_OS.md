# P0 GitHub Operating System and Repository Governance

## Context

GitHub must become the durable operating system for Kolibri Factory, not just a pile of PRs.

## Scope

- Labels.
- Milestones.
- Project board.
- Templates.
- Branch/PR/CI/release policies.
- Daily curator runbook.

## Acceptance

- P0/P1 work has issue or proposed issue.
- PR #46 split plan is tracked.
- Templates and policies exist.

## Forbidden

- No branch deletion.
- No PR/issue closure without explanation.
- No admin changes without owner approval.
