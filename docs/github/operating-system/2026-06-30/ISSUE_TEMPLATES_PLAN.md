## Issue Body Standard

Every P0/P1 issue must include:

- context;
- scope;
- acceptance criteria;
- forbidden scope;
- owner approval needed yes/no;
- linked docs/artifacts;
- labels;
- milestone;
- next command/envelope if agent-executable.

## Creation Policy

Do not create duplicate issues blindly. First map the required issue set to current open issues, then create only the missing gaps.
