# Kolibri vertical pack contracts

Vertical packs extend the universal Kolibri Platform with trusted,
release-bundled domain capabilities.

The manifest is declarative. It can enable only adapters, renderers and agent
capabilities that are already allowlisted in the release. It cannot load
arbitrary code, grant authority, store credentials, or bypass tenant policy.

The first example is `construction.estimates`. Future packs must define their
own domain contracts, data classification, source policy, approval policy and
evaluation corpus.
