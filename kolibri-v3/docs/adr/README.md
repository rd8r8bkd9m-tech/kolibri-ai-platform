# Architecture Decision Records

ADR фиксирует значимое архитектурное решение, а не журнал реализации.

1. Скопируйте `0000-template.md` в `NNNN-short-title.md`.
2. Укажите статус `proposed`.
3. До реализации согласуйте решение с владельцем затронутого контура.
4. После принятия поставьте `accepted` и обновите `PROJECT_MAP.md`,
   `SOURCE_OF_TRUTH.md` и structure checker, если контракт изменился.
5. Решение не удаляется: заменённый ADR получает `superseded by NNNN`.

Нумерация монотонная. Один ADR — одно решение.
